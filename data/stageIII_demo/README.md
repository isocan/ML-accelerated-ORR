# Stage III compact demonstration data

These files are compact, parser-ready excerpts for the public `mp-10260_111` worked example. They retain only the final `energy(sigma->0)` value, the VASP completion marker, and the VaspGibbs `G - E_dft` correction used by the notebook. They are not complete production VASP output archives.

The notebook can read these committed files directly after cloning the repository. No Google Drive access is required.
